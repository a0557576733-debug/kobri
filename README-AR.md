# حاسبة التمويل + Interakt (جهاز البيت)

هذه الخدمة تستخدم **نفس حسبة البوت القديم** وترد على العميل عبر Interakt تلقائيًا.

## المطلوب على جهاز عبدالرحمن (ويندوز)

1. تثبيت [Node.js LTS](https://nodejs.org/)
2. نسخ مجلد `finance-calc-server` للجهاز
3. إنشاء ملف `.env` من `.env.example`
4. وضع مفتاح Interakt:
   - افتح: https://app.interakt.ai/settings/developer-setting
   - انسخ **Secret Key**
   - ضعه في `.env` عند `INTERAKT_API_KEY=`
5. تشغيل:
   - دبل كليك على `start-calc.bat`
   - أو: `npm install` ثم `npm start`

## فتح الجهاز على الإنترنت (مهم)

لأن الجهاز في البيت، Interakt ما يوصل له مباشرة إلا عبر نفق:

### الأسهل: Cloudflare Tunnel
1. ثبت `cloudflared` على الجهاز
2. شغّل:
```bat
cloudflared tunnel --url http://127.0.0.1:5055
```
3. انسخ الرابط اللي يطلع (مثل `https://xxxx.trycloudflare.com`)

## ربط Webhook في Interakt

1. Settings → Developer Settings
2. فعّل Webhook لرسائل العملاء الواردة
3. Webhook URL:
```
https://XXXX.trycloudflare.com/webhook/interakt
```
4. احفظ

## كيف يستخدمها العميل

0. القائمة الرئيسية تظهر عند:
   - العميل يكتب **السلام عليكم** / **مرحبا** / **قائمة**
   - أو أنت (من المحادثة) تكتب الاختصار **`1`** → تظهر القائمة للعميل
   - أو العميل يكتب **`1`** وهو مو داخل مسار

   بعد ذلك القائمة:
   - تمويل شخصي
   - شراء مديونية
   - مبالغ التمويل (أمثلة 10,000 → 150,000 بعد اختيار عسكري/مدني)
   - إيقاف خدمات
   - ساعات الدوام
   - موقعنا
   - رقم المساعد

1. من القائمة: **تمويل شخصي** (أو يكتب: تمويل)
2. Interakt يعرض أزرار القطاع: مدني / متقاعد / عسكري (الكوبري ما يكرر السؤال)
3. ثم الكوبري يكمل: الراتب → الالتزامات → العقاري → النتيجة

> مهم: عطّل رد Interakt التلقائي على «السلام عليكم» حتى ما يصير ردّين (واحد من Interakt وواحد من الكوبري).

ما زال يدعم اللصق دفعة واحدة:

```
الراتب: 8000
الالتزامات: 1500
القطاع: مدني
العقاري: لا يوجد
الدعم: 0
```

السيرفر يحسب ويرد بـ:
1. **أعلى مبلغ** متاح + القسط
2. **قائمة مبالغ أقل** (كل 10,000 نزولًا حتى 10,000)

إذا العميل يبي أقل، يرسل المبلغ من القائمة (مثال: `90000`) فيحسب له قسط هذا المبلغ.

> ملاحظة: ضغط زر القطاع يُقرأ من `button_text` / `button_reply` وليس من نص الرسالة الأصلية.

## اختبار محلي بدون واتساب

```bat
npm test
```

أو:

```bat
curl -X POST http://127.0.0.1:5055/calculate/personal -H "Content-Type: application/json" -d "{\"message\":\"الراتب: 8000\\nالالتزامات: 1500\\nالقطاع: مدني\\nالعقاري: لا يوجد\\nالدعم: 0\"}"
```

## شراء المديونية

من واتساب: **شراء مديونية** (أو: مديونية)

المسار: قطاع → راتب → عقاري → التزامات (بدون قسط الشركة) → مبلغ المديونية → عرض

الحسبة: نسبة الاستقطاع حسب العقاري → المتبقي الشهري → أعلى مبلغ متاح →  
إذا أعلى من المديونية: الفائض = الأعلى − المديونية، والقسط على الإجمالي بفائدة 12%

في Interakt: اعمل Custom Auto Reply لكلمة `شراء مديونية` مع أزرار القطاع (مدني/متقاعد/عسكري) مثل التمويل الشخصي.

## لوحة التحكم الخارجية

بعد تشغيل السيرفر افتح:

```
http://127.0.0.1:5055/admin
```

أو عبر رابط Cloudflare:

```
https://XXXX.trycloudflare.com/admin
```

1. أضف في `.env`:
```
ADMIN_TOKEN=رمز-قوي-عندك
```
2. أعد تشغيل السيرفر
3. ادخل الرمز في صفحة اللوحة

### ماذا تفعل اللوحة؟
- نظرة عامة: عدد الجلسات / المسودات / الموقوف
- المحادثات: إيقاف / تشغيل / تصفير / إرسال القائمة
- إرسال رسالة نصية لأي رقم
- متابعة التقديم (فردي أو جماعي مع تأخير بين الرسائل)
- **متابعة جماعية آمنة** لعملاء «أخذ رابط التمويل»: تأخير أدنى 8 ثوانٍ، حد دفعة 30، سقف يومي 80، وتخطّي من توبع مؤخرًا

> لا تشارك `ADMIN_TOKEN` ولا تترك اللوحة مفتوحة بدون رمز قوي.

## ملاحظات

- لا تشغّل البوت غير الرسمي على رقم `0488` بنفس الوقت مع Interakt.
- الجهاز لازم يبقى فاتح + النفق شغّال.
- مدعوم الآن: **التمويل الشخصي** + **شراء المديونية**.
