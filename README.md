# الكوبري — نسخة عبدالرحمن

هذه نسخة مستقلة من كوبري التمويل (نفس الكود في `finance-calc-server`).

- الأصل يبقى في مستودع رائد: `fhaid10-ops/my-project`
- هذه النسخة لعبدالرحمن، جاهزة تتصير مستودع GitHub خاص فيه

## الخطوة الجاية

1. عبدالرحمن يفتح حساب GitHub بالجيميل حقه
2. ننشئ مستودع جديد باسمه (مثلاً `kobri`)
3. نرفع محتويات هذا المجلد `kobri/` إلى مستودعه
4. بعد الرفع، نقدر نحذف المجلد من مستودع رائد حتى ما يبقى تكرار

## التشغيل المحلي

```bash
cd kobri
npm install
npm test
npm start
```

لوحة التحكم: http://127.0.0.1:5055/admin

انسخ `.env.example` إلى `.env` وضع مفتاح Interakt.

شرح التشغيل الكامل (ويندوز / Cloudflare / Webhook) في [README-AR.md](README-AR.md).
